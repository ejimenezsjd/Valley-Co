# Valley-Co · Valle Compartido

Juego de granja en pixel-art para jugar solo o en pareja desde el navegador (móvil u ordenador).

**Jugar:** https://ejimenezsjd.github.io/Valley-Co/

## Jugar en pareja
1. Los dos abrís el juego y pulsáis **Jugar en pareja**.
2. Uno pulsa **Crear partida** y le pasa al otro el código de 6 letras que aparece arriba a la izquierda.
3. El otro escribe el código y pulsa **Unirme**.

La granja se guarda en el navegador de quien crea la partida. La conexión es directa entre los dos dispositivos (WebRTC con PeerJS).

## Controles
- Móvil: arrastra en la mitad izquierda para andar y pulsa **USAR**.
- Ordenador: flechas o WASD para andar, barra espaciadora o Enter para usar.
